# Agent Instructions

## Communication
- Be brief in responses.

## Coding approach
- Don't split code into separate modules until there is a concrete need to share it across modules.
- Prefer some code duplication over making premature abstractions.

## Documentation
- Prefer code comments over separate documentation files when describing protocols and behavior. Only add separate documentation files for high-level concepts.
- When referring to paths in project docs, omit the leading `` prefix.
