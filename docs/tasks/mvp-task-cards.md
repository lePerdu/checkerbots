# CheckerBots MVP Task Cards

These task cards are intended for coding agents or human contributors working on the earliest MVP milestones. They are based on the first suggested issues from `docs/epics-and-issues.md`, with a few additional early tasks so work can continue without redefining scope each time.

## Recommended order

1. `task-01-create-monorepo-structure.md`
2. `task-02-choose-primary-stacks.md`
3. `task-03-add-baseline-tooling.md`
4. `task-04-write-initial-readme.md`
5. `task-05-define-shared-robot-protocol-v0.md`
6. `task-06-define-core-shared-types.md`
7. `task-07-create-rules-engine-module.md`
8. `task-08-implement-new-game-board-initialization.md`
9. `task-09-create-coordination-server-app.md`
10. `task-10-create-simulated-robot-app.md`
11. `task-11-define-board-coordinate-model.md`
12. `task-12-implement-legal-move-generation.md`

## Usage notes

- Prefer assigning one task card at a time.
- If the repo evolves, update task cards before assignment if the expected files/areas change.
- Tasks are intentionally scoped to avoid broad multi-subsystem edits in a single pass.
